# Velocity
A modern DPI bypass wrapper for Zapret with integrated DNS management.

## Features
- 🛡️ Multi-strategy Zapret DPI bypass
- 🌐 One-click DNS switching (Cloudflare, Quad9, Google, AdGuard, NextDNS)
- 🎨 Modern monospace UI built with Tauri + React
- 📦 Self-contained portable executable

## Requirements
- Windows 10/11 (64-bit)
- Administrator privileges

## Building from Source
```bash
npm install
npm run tauri dev      # Development
npm run tauri build    # Production build
